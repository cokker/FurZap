# FurZap 1.3.1

- Прокрутка под указателем над вложенными блоками во всех разделах.
- На границах вложенного списка или редактора колесо прокручивает страницу.
- Исправлены координаты при возврате в раздел и изменении размера окна.
- Скруглены редактор списков и результаты проверок; блок результатов стал компактнее.
- Форматы engine и data не изменены. Для обновления достаточно заменить FurZap.exe.

Сборка и автоматические проверки выполняются Windows workflow перед публикацией. Проверки не запускают драйвер и не проверяют обход блокировок в реальной сети.
