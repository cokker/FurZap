# FurZap 1.3.0

- Разделы сохраняют прокрутку, выбор и черновики списков; переходы не меняют прозрачность окна.
- На главной отдельно показаны состояние движка и результаты проверки сайтов.
- Возврат к рабочей конфигурации показывает стратегию и дату сохранения.
- Обновление FurZap из GitHub: описание версии, прогресс, отмена и проверка SHA256 перед подтверждением установки. Папки engine и data сохраняются.
- Дракон реагирует на запуск, остановку и проверки; доступны спокойный, уменьшенный и скрытый режимы.
- Избранные и недавние стратегии, заметки и результаты последней проверки.
- Отдельное мини-окно с управлением запуском.
- Отчёт об ошибке с удалением личных данных и просмотром перед сохранением; автоматической отправки нет.
- Подсказки, состояния выполнения и масштаб до 200%.

Для первой установки скачай FurZap-Windows-x64.zip и распакуй целиком. Для обновления закрой приложение и замени только FurZap.exe, сохранив engine и data. Встроенная проверка будущих обновлений находится в разделе «Инструменты».

Проверка: 110 проверок логики и 58 проверок интерфейса пройдены под Mono/Xvfb. Замер текущего Linux-предпросмотра: 39 кадров/с, у 1.2.2 на том же стенде — около 36. Цель цикла — 60 Гц; стабильные 60 FPS на Windows не подтверждены. Замена EXE обновлятором, UAC, драйвер и службы требуют проверки на Windows.

НОВОЕ В 1.2.0
• Полностью собственные переключатели: исправлена отрисовка старых фрагментов
  текста поверх настроек. Перерисовка при навигации и изменении окна обновлена.
• Проверки Discord, YouTube, VRChat: прямые HTTPS GET, без системного прокси.
  HTTP 2xx/3xx считается доступностью указанного адреса. При HTTP-ошибке
  отдельно показано, удалось ли установить TLS. Время — HTTP, не игровой пинг.
  Эти проверки не подтверждают голос/UDP, видео, вход в аккаунт или CDN.
  Для голоса есть отдельная ручная отметка после разговора с собеседником.
• Подбор всех 22 стратегий: прогресс, отмена, журнал результата. Рейтинг —
  количество доступных адресов, затем суммарное время запросов. Работающий
  процесс/собственная служба временно останавливается. После завершения,
  ошибки или отмены возвращаются прежние файлы и состояние движка.
  Чужая служба не переключается. Если восстановление не удаётся, показывается
  ошибка и путь к сохранённой копии data/scan-recovery.
  Новая стратегия выбирается явно; выбор сам по себе не перезапускает движок.
• Профили сохраняют стратегию, игровые порты, IPSet, списки, флаг обновлений
  и ACTIVE-пакеты. Сохрани свои варианты под названиями «На каждый день»,
  «VRChat», «Другая сеть». Это имена, а не заранее проверенные пресеты.
  При применении профиля работающий движок перезапускается с его настройками;
  остановленный остаётся остановленным. Существующий профиль не затирается:
  обновлённый набор можно сохранить под новым именем.
• История перед изменениями списков, портов, IPSet, пакетов и выбранной стратегии.
  Полный откат из списка и кнопки «Отметить рабочую» / «Вернуть рабочую».
  Отсутствовавшие файлы тоже учитываются; контрольные суммы проверяются
  до восстановления. Hosts, кэш Discord и системные TCP-настройки в эти
  профили не входят. Для hosts сохранены отдельные резервные копии/удаление блока.
• Трей: статус, запуск/остановка и переключение сохранённых профилей.
• Дракон: сгенерированная поза сна, пробуждение при наведении, реакция на
  успешное действие/ошибку и индикатор проверки. Звуки по желанию (выключены
  по умолчанию), анимации можно отключить.
• Оранжевая, бирюзовая и лавандовая темы. Масштаб содержимого 100/125/150%:
  в узком окне автоматически уменьшается до помещающегося размера.
  Компактный режим уменьшает окно и боковую панель, скрывает бокового дракона.
• Ошибки дополнены подсказками; технические подробности остаются в журнале.

БЫСТРЫЙ ЗАПУСК
1. Извлеки ВЕСЬ архив, например в C:\FurZap. Не запускай EXE внутри ZIP.
2. Останови предыдущий Zapret. Если он установлен службой из другой папки,
   открой старый service.bat и удали старую службу.
3. Открой FurZap.exe. При обычном запуске приложение запросит права администратора.
4. Открой «Стратегии», выбери прежнюю рабочую стратегию и нажми «Выбрать и запустить».
   Если не помнишь её — начни с general, затем проверь нужные сайты и приложения.
5. Для автозапуска: «Служба» → «Установить / применить».
   Папку установленной службы нельзя перемещать. Сначала удали службу в интерфейсе.

ТРЕБОВАНИЯ
Windows 10/11 x64, .NET Framework 4.7.2 или новее, права администратора.
Python, Node.js, браузерный движок и установка дополнительных пакетов не требуются.
EXE не имеет цифровой подписи издателя. Исходники находятся в папке source.
Не отключай антивирус; при сомнениях проверь файлы или пересобери оболочку из исходников.

ИНТЕРАКТИВНЫЕ ИСХОДНЫЕ ИНСТРУМЕНТЫ
Исходные тесты доступны через оригинальный менеджер service.bat (пункт 12).
Для них сначала останови процесс FurZap и удали его службу; после тестов
службу можно установить снова. Дождись штатного завершения исходного скрипта.
Встроенный подбор в разделе «Проверки» работает в самом FurZap с отменой
и возвратом прежнего состояния; он не заменяет расширенные тесты оригинала.
В «Инструменты → Исходный менеджер» доступно полное оригинальное меню service.bat,
включая удаление общих WinDivert-служб и расширенные исправления диагностики.
Пока исходный инструмент открыт, FurZap блокирует собственные изменяющие действия.

КАК ПРИМЕНЯЮТСЯ НАСТРОЙКИ
Выбор стратегии не переключает уже работающий движок.
После изменения портов, списков или fake-пакетов:
— обычный процесс: остановить и запустить;
— служба: нажать «Установить / применить», чтобы обновить и параметры службы.
FurZap не меняет чужую службу zapret из другой папки.
Обычное удаление службы FurZap не удаляет общие драйверы WinDivert других программ.
При запуске процесса/установке службы включаются TCP timestamps, как в исходной сборке.
Установка службы включает её автоматический запуск с Windows.
При первом открытии движок сам не запускается.

ЗАКРЫТИЕ
По умолчанию крестик закрывает приложение. Если работает обычный процесс,
появится выбор: остановить его и выйти либо оставить и свернуть в трей.
Служба продолжает работать независимо от окна. Остановить её можно на странице «Служба».
В «Настройки» можно включить постоянное сворачивание в трей по крестику.

ГДЕ ЛЕЖАТ ФАЙЛЫ
engine — полная копия исходной сборки 1.10.3 с оригинальными BAT, DLL, SYS и EXE.
data/preferences.txt — настройки оболочки (создаётся при работе).
data/furzap.log — локальный журнал (создаётся при работе).
data/backups — копии перед изменениями (создаётся при работе).
engine/utils/test results — результаты исходных тестов.
source — полные исходники C# и сборочный скрипт build-windows.cmd.
preview.png — снимок реально запущенного интерфейса в режиме предпросмотра.

ВОССТАНОВЛЕНИЕ
Чтобы вернуть изменённый список или пакет, останови движок и скопируй нужный
.bak из data/backups обратно в engine/lists или engine/bin с исходным именем.
Для hosts используй «Удалить блок FurZap»: это сохраняет остальные записи файла.
Полная копия hosts также лежит в data/backups; её можно восстановить вручную,
но это отменит и последующие изменения других программ.

ОБНОВЛЕНИЕ ДВИЖКА
Оболочка рассчитана на структуру предоставленной версии 1.10.3. Проверка обновлений
показывает версию из репозитория и предлагает открыть релизы; движок автоматически
не заменяется. Не смешивай файлы различных версий поверх работающей службы.

ПРОВЕРКИ И ОГРАНИЧЕНИЯ
EXE скомпилирован как Windows x64 .NET GUI-приложение с официальными
reference assemblies Microsoft .NET Framework 4.7.2, а не с API Mono.
В 1.0.1 исправлена ошибка Method not found: System.String.Split(Char, StringSplitOptions).
Все Split/TrimStart используют совместимые перегрузки с массивом символов.
Дракон создан встроенной генерацией изображений, PNG с прозрачностью встроен в EXE.
Его исходник: assets/dragon.png; описание генерации: assets/prompt.txt.
77 автоматических проверок прошли: все стратегии, подстановка портов, обработка
экранированного !, валидация доменов/IP, настройки, резервные копии, замена пакетов,
экранирование аргументов. Интерфейс запущен через Mono, проверены семь страниц.
Windows UAC, SCM, WinDivert и реальный обход блокировок в этой Linux-среде не тестировались.
Это нужно проверить на твоём Windows и подключении. Статус «движок запущен» означает
наличие процесса/службы, а не доказанную доступность YouTube, Discord или VRChat.
FurZap не исправляет автоматически зависания VRChat и не подбирает стратегию без тестов.
